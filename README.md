# CliffDivers Balance Lab

Application web interactive pour équilibrer les modules, l’énergie et les expéditions de **CliffDivers**.

## Ouvrir l’application

**[Lancer CliffDivers Balance Lab](https://lazysmokies.github.io/cliffdivers-balance-lab/)**

Aucune installation ni création de compte n’est nécessaire. L’application fonctionne directement dans un navigateur récent.

## Fonctions principales

- composition du sac par glisser-déposer sur les slots Top, Side et Down ;
- simulation du flux d’énergie et du temps d’exploration ;
- éditeur complet de scénarios et de conditions initiales ;
- modification des paramètres énergétiques des modules ;
- analyse automatique des builds, frontières de Pareto et sensibilité ;
- simulation probabiliste Monte-Carlo ;
- comparaison de builds ;
- export et import de profils JSON ou CSV ;
- versions, notes de balance et historique local.

## Données et partage

Les profils et l’historique sont enregistrés localement dans le navigateur de chaque utilisateur. Utilisez l’export JSON pour partager un état complet entre collègues.

## Publication

Le contenu de `dist/` est publié automatiquement sur GitHub Pages après chaque mise à jour de la branche `main`.
